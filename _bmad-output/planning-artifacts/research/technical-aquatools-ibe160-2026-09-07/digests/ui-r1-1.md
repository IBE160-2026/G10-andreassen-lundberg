# Observasjoner fra AquaTools

Utgiver: AquaTools. Publiseringsdato ukjent. Alle sidene besøkt 2026-09-07. Evidens: synlig DOM i brukerens nettleser. Tillit: middels, én primærkilde; ingen uavhengig funksjonstest. Personlige feltverdier er utelatt.

| Kilde | Observert grensesnitt |
| --- | --- |
| https://aquatools.vercel.app/ | Sju verktøy med navn og lenker. |
| https://aquatools.vercel.app/forplanner | Siloer med kapasitet, beholdningsdato, fôrtype og reserve. Merder med daglig forbruk, tidspunkt for stans i fôring og silotilknytning. Leveringer og forslag med mengdetrinn, låsing og forhåndsvisning før registrering som avtalt. |
| https://aquatools.vercel.app/kalkis2 | Forbruksperiode, tillegg til behov, dataimport, siloer og bestilling avrundet til sekker. |
| https://aquatools.vercel.app/dogngrader | Temperatur og datoberegning, valg mellom manuell temperatur, BarentsWatch og XLSX/CSV, kalender og merking av datagrunnlag. |
| https://aquatools.vercel.app/lokalitetspanel | Ukefilter, sortering, kart, lokalitetssøk og oppgitt rapporteringsdekning. |
| https://aquatools.vercel.app/dodfiskfordeler | Fordeling av registrert opptak over en mulig periode, merder, årsaker, justering og import; estimat skilt fra observasjon. |
| https://aquatools.vercel.app/slangetrykk | Lengdebasert hurtigberegning og valg for å organisere flere lokaliteter og merder. |
| https://aquatools.vercel.app/stingray-status | Innlogging kreves for nodeoversikt; inngang til lokal eksportfilanalyse synlig. Interne funksjoner ikke undersøkt. |

Begrensninger: ingen kildekode lest, ingen beregningsresultater validert, ingen innlogging gjennomført. Søket etter aktuell offisiell IBE160-emnetekst ga ingen anvendelig primærkilde. Det sier ikke at emneteksten ikke finnes. Tilgjengelig oppgavetekst og regler for gjenbruk må innhentes før endelig prosjektvalg.
